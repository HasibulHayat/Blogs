7. Practical projects
Don't wait until Lesson 65 to start building things.

Build these progressively as you learn.










Project 1 — Thread-safe Banking System

After Phase 3.
- Multiple concurrent deposits and withdrawals.
- Prevent race conditions.
- Ensure balance consistency.
Tests: synchronization, atomicity, visibility













Project 2 — Multithreaded Task Processing System

After Phase 4–5.
- Submit multiple jobs.
- Execute using thread pools.
- Handle failures and timeouts.
- Coordinate workers.
Tests: ExecutorService, Future, BlockingQueue, Semaphore













Project 3 — Concurrent API Aggregator

After Phase 4.
- Call multiple APIs concurrently.
- Combine responses.
- Handle timeouts and failures.
- Implement cancellation.
Tests: CompletableFuture, thread pools, timeouts













Project 4 — Concurrent Turf Booking Engine

After Phase 6.
- Multiple customers booking the same slot.
- Prevent double booking.
- Handle simultaneous payment requests.
- Handle duplicate requests.
- Use proper database transactions and locking.
Tests: Spring Boot, PostgreSQL, transactions, locking, idempotency
